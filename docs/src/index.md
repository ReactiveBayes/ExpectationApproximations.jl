# ExpectationApproximations

Numerical backends for the expectation protocol of
[BayesBase](https://github.com/ReactiveBayes/BayesBase.jl): quadrature, cubature, sigma points and
sampling compute ``\mathbb{E}_q[f]`` through `BayesBase.expectation` and
`BayesBase.prepare_expectation`. Nothing is exported; the names are public and used qualified.
