Writing a backend

A backend is any value for which two methods of BayesBase are defined:

  • BayesBase.supports_expectation(backend, ::Type{F}, ::Type{Q}), which declares that the backend handles integrands of type F under distributions of type Q;
  • either BayesBase.prepare_expectation(backend, q), which returns something BayesBase.expectation(prepared, f) can evaluate, or BayesBase.expectation(backend, f, q) directly, for a closed form.

The simplest way is to return a BayesBase.ExpectationPointSet(points, weights) from prepare_expectation. Products of distributions, routers and the projections of this package then work with the new backend. For example, a two-point rule for Gaussians, exact up to degree 3:

using ExpectationApproximations, Distributions
import BayesBase
const EA = ExpectationApproximations

struct TwoPoint end
BayesBase.supports_expectation(::TwoPoint, ::Type, ::Type{<:Normal}) = true
BayesBase.prepare_expectation(::TwoPoint, q::Normal) =
    BayesBase.ExpectationPointSet(mean(q) .+ std(q) .* [-1.0, 1.0], [0.5, 0.5])

BayesBase.expectation(TwoPoint(), x -> x^2, Normal(1.0, 2.0))
5.0

The conformance suite

ExpectationApproximations.Testing checks a backend against expectations with known values. The backends of this package pass the same checks:

  • the backend supports each case and computes it correctly;
  • a backend labelled exact is exact;
  • the prepared expectation equals the direct one, or is reproducible for a stochastic backend;
  • the result is inferred, and evaluating a prepared expectation allocates nothing;
  • dual numbers pass through;
  • a product of two cases is supported and correct.

Testing.conformance returns the checks, and Testing.test_backend records them as tests in the test suite of the backend's package. A backend for positive or unit-interval variables should also pass Testing.boundary_cases: integrands singular at the boundary, such as log x under a Gamma with a shape below one, which are common in inference and where rules made for polynomials fall short.

using ExpectationApproximations.Testing: Case, conformance
cases = [Case(Normal(0.5, 1.5), x -> x^2, 0.5^2 + 1.5^2), Case(Normal(0.0, 1.0), x -> x^3, 0.0)]
checks = conformance(TwoPoint(), cases)
unique(check.name for check in checks), all(check -> check.passed, checks)
(["supports", "correct", "prepared equals direct", "inferred", "allocation-free", "duals pass", "product"], true)

A case that the rule cannot compute exactly, $\mathbb{E}[x^4] = 3$ under a standard Gaussian, fails the "correct" check:

checks = conformance(TwoPoint(), [Case(Normal(0.0, 1.0), x -> x^4, 3.0)])
[check.name for check in checks if !check.passed]
1-element Vector{String}:
 "correct"

ExpectationApproximations.Testing.conformance — Function
conformance(backend, cases; rng = Xoshiro(1234)) -> Vector{Check}

Checks backend on every Case, without recording tests:

  • supports_expectation: the backend supports the case;
  • correct: the expectation equals the expected value, to the case's rtol;
  • exact label holds: where the backend is labelled ExpectationExact, to rounding;
  • prepared equals direct: a prepared expectation gives what a direct one gives, for a deterministic backend;
  • reproducible: the same random number generator gives the same result, for a stochastic one;
  • inferred: evaluating a prepared expectation is type-stable;
  • allocation-free: evaluating a prepared expectation allocates nothing;
  • duals pass: ForwardDiff differentiates through the integrand of a prepared expectation;
  • product: the expectation of f₁(x) f₂(y) under the product of the first two cases' distributions is the product of their expectations, for a deterministic backend that supports products.

Stochastic backends receive rng through with_expectation_rng.

ExpectationApproximations.Testing.boundary_cases — Function
boundary_cases(; rtol = 1e-10) -> Vector{Case}

Cases whose integrands are singular at the boundary of a positive or unit-interval variable, at shapes of one and below, where the mass piles up at that boundary: log x under Gamma and Exponential distributions, log x and log(1 - x) under Beta distributions, and the log-density of a Poisson count under a Gamma rate. These are the integrands of inference, such as an average energy, and quadrature rules made for polynomials, such as Gauss–Laguerre and Gauss–Jacobi, converge slowly on them. A backend for these families should pass them.
