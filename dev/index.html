ExpectationApproximations

ExpectationApproximations computes expectations $\mathbb{E}_q[f(x)]$ of a function $f$ under a distribution $q$ numerically. Examples are $\mathbb{E}[\log x]$ under a Gamma distribution, $\mathbb{E}[\sigma(a + b x)]$ under a Gaussian, and the expected log-likelihood of a factor in a model. The package implements quadrature, cubature, sigma points, exact sums and sampling as backends of the expectation protocol of BayesBase.

The package also approximates a density, given as a Julia function, by a Gaussian. Approximate inference uses three such Gaussians: the Laplace approximation at the mode (laplace), the Gaussian with the moments of the density, as in expectation propagation (moment_matching), and the Gaussian closest to the density, as in variational inference (gaussian_variational). Related functions compute the moments of functions of random variables. For a variable that must be positive, a probability or a probability vector, the Gaussian approximation is made in unconstrained coordinates and transformed back.

A first example

Gauss–Legendre quadrature in the logarithm of the variable computes the expected logarithm of a Gamma variable:

using ExpectationApproximations, Distributions
import BayesBase
const EA = ExpectationApproximations

q = Gamma(3.0, 2.0)
BayesBase.expectation(EA.UnconstrainedLegendre(), log, q)
1.6159315156584944

The exact value is $\psi(3) + \log 2$:

using SpecialFunctions: digamma
digamma(3.0) + log(2.0)
1.6159315156584126

Usually the rule is not picked by hand: EADefault chooses the rule for the family of each distribution. A backend can also be prepared once for a distribution and then evaluated for many functions without allocating:

prepared = BayesBase.prepare_expectation(EA.EADefault(), q)
BayesBase.expectation(prepared, x -> x^2), BayesBase.expectation(prepared, sqrt)
(47.99999999999333, 2.349964007466657)

laplace takes the logarithm of an unnormalised density and a starting point. For a skewed density on the real line:

result = EA.laplace(x -> x - exp(x) / 2, 0.0)
result.distribution, result.converged
(Normal(0.6931471805600254, 0.9999999999999599), true)

Related packages

ExpectationApproximations is part of the ReactiveBayes ecosystem:

PackageRole
BayesBasedefines the expectation protocol: expectation, prepare_expectation, and how a backend says what it supports
ExpectationApproximationsimplements backends for the protocol, and the Gaussian approximations built on them
DeltaMessagePassingRulesturns these approximations into message passing rules for nodes that have no hand-written ones
RxInferruns inference on models without hand-written rules with infer(...; fallback = LocalLaplace()), LaplacePropagation(), ExpectationPropagation() or NaturalGradientPropagation()

The package does not depend on message passing, and its backends and approximations can be used on their own.

Installation

import Pkg
Pkg.add("ExpectationApproximations")

The package exports no names. Its public names are used qualified, as in the examples above, usually through const EA = ExpectationApproximations. The protocol functions expectation and prepare_expectation belong to BayesBase and are called as BayesBase.expectation.

ExpectationApproximations.ExpectationApproximations — Module
ExpectationApproximations

Numerical backends for the expectation protocol of BayesBase. Quadrature, cubature, sigma points and sampling compute E_q[f] through BayesBase.expectation and BayesBase.prepare_expectation. The package also implements Gaussian approximations of a density (Laplace, moment matching and the variational Gaussian), linearisation, and transforms to unconstrained coordinates for variables with a constrained domain.

Nothing is exported. The names are public and used qualified, such as ExpectationApproximations.GaussHermite.
